# 🧭 Quiz: Onde Você Se Encaixa?

Uma aplicação web interativa (https://davisonesoliveira-netizen.github.io/quiz-politico/), leve e didática projetada para público geral. O objetivo do quiz é explicar conceitos do espectro político de forma prática e acessível, utilizando situações e dilemas cotidianos em vez de termos técnicos ou jargões da ciência política.

---

## 🎯 Objetivos do Projeto

- **Linguagem Simples:** Traduzir visões de mundo (economia, segurança, saúde, trabalho) em escolhas do dia a dia sem julgamento de valor.
- **Transparência:** Mostrar ao final em qual direção do espectro (Esquerda x Direita) as escolhas do usuário penderam.
- **Experiência Didática:** Apresentar a pontuação de forma visual em uma barra de equilíbrio continuo com o centro neutro (50%/50%).

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído do zero utilizando apenas tecnologias nativas da web (sem dependências externas de frameworks):

- **HTML5:** Estruturação das telas e meta tags para compartilhamento social (Open Graph).
- **CSS3:** Estilização moderna, responsiva (focada em dispositivos móveis) e layout limpo.
- **JavaScript (ES6):** Lógica do quiz (embaralhamento de alternativas, cálculo final e renderização do histórico).

---

## 📱 Destaques de Recursos

1. **Aleatoriedade de Opções:** A ordem das alternativas A/B é sorteada a cada execução para evitar viés de posicionamento.
2. **Pontuação Oculta:** O resultado final e o gráfico só são revelados após a última pergunta.
3. **Histórico Detalhado:** Exibe todas as escolhas feitas pelo usuário organizadas por polaridade.
4. **Pronto para Redes Sociais:** Inclui meta tags Open Graph pré-configuradas para gerar cartões visuais ao compartilhar o link em aplicativos como o WhatsApp.

---

## 🚀 Como Executar

Por ser uma aplicação estática, basta abrir o arquivo `index.html` em qualquer navegador web ou acessar o link do **GitHub Pages** do repositório.
